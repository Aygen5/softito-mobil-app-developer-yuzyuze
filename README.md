# Softito Mobil App Developer (Yüzyüze)

Bu repository, Softito Mobil App Developer (Yüzyüze) eğitimi kapsamında gerçekleştirilen ders içi uygulamalar, projeler ve ödevlerin takibi için oluşturulmuştur.

## İçerik

- **15.10**: Flutter'a giriş ve temel bileşen (widget) çalışmaları
- **19.10**: Flutter widget yapısı, layout pratikleri ve pekiştirme ödevleri üzerinde çalışıldı.
- **20.10**: Girişimcilik projesi arayüz geliştirmeleri ile oto kiralama ödevi uygulaması tamamlandı.
- **21.10**: Staj takip uygulaması mimarisi ve ekran tasarımları geliştirildi.
- **22.10**: Alışkanlık takibi uygulaması geliştirildi ve Flutter terimler sözlüğü dokümantasyonu hazırlandı.
- **27-30.10**: Canlı FakeStore REST API entegrasyonlu `mini_magaza_canli_api` e-ticaret uygulaması, katmanlı mimari (models, services, widgets, screens), 4 UI durumu yönetimi, filtreleme/arama ve detaylı öğrenci rehberi hazırlandı.
- **02.11**: Dart 3 modern özellikleri (sealed class, record, mixin), Row taşma çözümleri, ValueNotifier ile state yönetimi, go_router sekme navigasyonu ve katmanlı API servis mimarisi pekiştirildi.
- **03.11**: Firebase Cloud Firestore entegrasyonu, gerçek zamanlı veri akışı (StreamBuilder) ile öğrenci-proje yönetim ekranı ve CRUD işlemleri katmanlı mimariye uygun şekilde geliştirildi.
- **04.11**: Firebase Cloud Messaging (FCM) ile push bildirim altyapısı, flutter_local_notifications ile ön plan yerel bildirimleri, image_picker ile medya seçimi ve Firebase Cloud Storage dosya yükleme/yönetim mimarisi geliştirildi. Kök dizine detaylı `ogrenci_rehberi.md` eklendi.
